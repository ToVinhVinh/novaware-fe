Hướng dẫn chạy Project

A. Chạy Server (API cho Frontend)
1. Kiểm tra Python: dùng Python 3.11.9 (khuyến nghị, tránh 3.12 vì lỗi).
2. Mở terminal và cd vào thư mục dự án `Novaware-Django`.
3. Tạo môi trường ảo: `python -m venv venv` (hoặc tên khác).
4. Kích hoạt môi trường ảo:
   - PowerShell (Windows): `.\venv\Scripts\Activate.ps1`
   - macOS/Linux: `source venv/bin/activate`
   - Khi kích hoạt thành công sẽ thấy `(venv)` ở đầu dòng lệnh.
5. Cài đặt thư viện: `pip install -r requirements.txt`
6. Chạy server (Django):
- Chạy: `python manage.py runserver`
- Mặc định chạy trên port: `http://localhost:8000/`

B. Chạy ứng dụng Streamlit / app_recommendation

2. Mở terminal và cd vào thư mục dự án `Novaware-Django`.

C. Chạy Website
1. Kiểm tra Node.js: cài đặt Node.js phiên bản 16 trở lên (khuyến nghị Node.js 18 hoặc 20).
2. Mở terminal và cd vào thư mục dự án `Novaware-FE`.
3. Cài đặt dependencies:
   - Nếu dùng npm: `npm install`
   - Nếu dùng pnpm: `pnpm install` (khuyến nghị)
   - Nếu dùng yarn: `yarn install`
4. Chạy website (development mode):
   - Nếu dùng npm: `npm run dev`
   - Nếu dùng pnpm: `pnpm dev` (khuyến nghị)
   - Nếu dùng yarn: `yarn dev`
5. Mặc định chạy trên port: `http://localhost:3000/`
